# TodoTracker Beta

## 中文

TodoTracker 是一個放在 Chrome 工具列的小工具，幫你記錄工作時間、管理 Todo，並在指定時間提醒你。

### 安裝

1. 開啟 Chrome，前往 `chrome://extensions`
2. 開啟右上角的「開發人員模式」
3. 點選「載入未封裝項目」
4. 選擇這個 `extension` 資料夾
5. 將 TodoTracker 固定到 Chrome 工具列

### 基本使用

- 點擊工具列上的 TodoTracker，開始或停止計時
- 在 Todo 頁面新增工作項目
- 可設定優先級：緊急、高、一般、低
- 可設定截止日期與提醒時間
- 到提醒時間時，Chrome 會發送通知
- 完成 Todo 後，它會停止提醒

### 資料與隱私

目前資料會儲存在你的 Chrome 本機儲存空間，不會自動上傳到其他服務。

### Beta 測試回報

如果遇到問題，請提供：

- 你當時做了什麼
- 預期結果
- 實際發生的情況
- Chrome 版本與作業系統

截圖或操作步驟也很有幫助。

## English

TodoTracker is a small Chrome extension for tracking work time, managing Todos, and reminding you when it is time to act.

### Installation

1. Open Chrome and go to `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select this `extension` folder
5. Pin TodoTracker to the Chrome toolbar

### How to use it

- Click TodoTracker in the toolbar to start or stop a timer
- Add and manage work items from the Todo page
- Set a priority: Urgent, High, Normal, or Low
- Set a due date and reminder time
- Chrome will show a notification at the reminder time
- Completed Todos will no longer send reminders

### Data and privacy

Your data is currently stored in Chrome's local storage. It is not automatically uploaded to another service.

### Beta feedback

When reporting a problem, please include:

- What you were doing
- What you expected to happen
- What actually happened
- Your Chrome version and operating system

Screenshots and reproduction steps are also helpful.
