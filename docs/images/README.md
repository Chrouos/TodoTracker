# 截圖放這裡

README.md 會抓這個資料夾的檔案。**檔名要一模一樣**（副檔名 `.png`），放進來就會自動顯示。

Windows 截圖：`Win` + `Shift` + `S` → 框選 → 貼到小畫家存成 PNG，或直接從剪貼簿存檔。

| 檔名 | 拍哪裡 | 建議寬度 | 內容要有什麼 |
|---|---|---|---|
| `hero.png` | 網頁 `/` 總覽 | 1200–1600 | 深色計時面板正在計時 + 下方 KPI 與依專案長條。這張放在最上面當門面，最重要 |
| `popup.png` | 擴充 popup | 就是 popup 原寬 380 | 計時中，工作紀錄框裡有幾行帶時間戳的內容 |
| `reports.png` | 網頁 `/reports` | 1200–1600 | 甜甜圈 + 右側圖例 + 底下折線圖 |
| `timeline.png` | 網頁 `/reports` 的時間軸區塊 | 1200–1600 | 幾天的色塊分佈，看得出上下班時段 |
| `log.png` | 網頁 `/log` | 1200–1600 | 一天的區塊展開，底下的紀錄框有內容 |
| `projects.png` | 網頁 `/projects` | 1200–1600 | 至少要有兩層縮排的專案樹，右邊看得到累加時數 |
| `todos.png` | 網頁 `/todos` | 1200–1600 | 有「歷時 N 天」「逾期 N 天」badge 的項目 |

## 拍之前

> [!WARNING]
> 你目前的資料裡有內網 GitLab 連結與表單編號。如果這個 repo 是公開的，拍之前先確認畫面上沒有：
>
> - 內網網址、IP、主機名稱
> - 工單編號、客戶名稱
> - 任何不該外流的專案名
>
> 兩個做法：先把敏感的 todo 收合／篩掉再拍，或是到 **設定 → 匯出備份** 存一份，另外建幾個示範專案拍完再匯入還原。

## 小技巧

- 瀏覽器縮放設 **100%**，Windows 顯示比例如果是 125% 拍出來會有點模糊，可以先調 100%
- 網頁那幾張把瀏覽器視窗調到約 1280px 寬，剛好對上內容欄的 960px 版面
- 只想拍某個區塊的話，先把其他區塊用 `[-]` 收起來，畫面會乾淨很多
- popup 那張：在擴充圖示上按右鍵 → 檢查，或直接開 `chrome-extension://<你的擴充ID>/src/popup/popup.html` 當一般頁面拍，比較好框
