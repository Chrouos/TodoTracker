## 八、操作流程（2026-11-02 檢查）

### 會誤操作或資料不一致

- [x] popup 焦點在按鈕上按空白鍵會開始/停止計時：只有焦點不在可操作元素時才當快捷鍵。
- [x] 停止後補寫的內容在 popup 關閉時遺失：輸入時先存成草稿，重開後還原。
- [x] popup 刪 Todo 不會確認：改為與管理頁相同的確認。
- [x] 刪除紀錄沒有確認也沒有提示：顯示提示並可復原。
- [x] popup 收起進階欄位後，隱藏的父任務與截止日仍套用：收起時重設。
- [x] 管理頁開著時，其他地方改的資料不會更新：有變更才重繪，列內編輯中則延後。
- [x] 閒置提醒只在 popup 出現：回到電腦時發通知，管理頁也顯示橫幅。

### 常用流程

- [x] 計時中無法修改開始時間：popup「編輯細節」與計時分頁都可改，不能晚於現在。
- [x] 沒有全域快捷鍵：Alt+Shift+K 開始／停止計時，Alt+Shift+J 開啟 popup；設定頁可看目前按鍵並前往變更。
- [x] 報表無法切換上一期／下一期：今天、本週、本月可前後切換，過去的區間與前一期整段比較。
- [x] popup Todo：篩選移出新增面板、子任務有層級、標示逾期與今天到期、預設只列未完成，分頁與篩選會保留。

### 小修正與資料保護

- [x] `[x]` 只代表刪除與停止，`[-]`、`[+]` 只代表收合與展開：popup 刪除改用 `[x]`，補寫紀錄與排程開關改用文字。
- [x] Todo 表單與排程標籤誤用「現在在做什麼？」。
- [x] 儲存設定與匯入成功改用 toast；錯誤仍用對話框，避免太快消失或被對話框蓋住。

- [x] 匯入與清空前自動下載備份；檔案無效時不會詢問、備份或覆蓋。
