# Extension 視覺檢視紀錄（2026-10-29）

以 Playwright 搭配示範資料（巢狀專案、逾期 Todo、計時中狀態）實際渲染 popup 與 options 各分頁後整理。

## 一、顯示錯誤（優先修）

- [x] 報表「專案時間與每日趨勢」內的「全部專案」「Heatmap」預設收起，但標記固定顯示 `[-]`，切換時也不會更新，看起來像沒有資料。
- [x] 每日工作回顧日曆的欄位標題重複顯示星期（`2026/10/19（週一）　一`）。`formatDisplayDate` 已含星期。
- [x] 回顧日曆天數多時（例如「本月」）右側被裁切，沒有可橫向捲動的提示，時間軸與日期標題也會隨捲動消失。
- [x] 回顧日曆最底部的時間標籤（例如 `18:00`）被切掉一半。（時間軸本身會依紀錄自動延伸，紀錄不會被隱藏。）
- [x] options 頁在窄寬度（約 420px）時分頁列超出畫面，整頁出現橫向捲動。

## 二、日曆

- [x] 月檢視每格都顯示「計畫 0 小時 00 分／實際 0 小時 00 分」，數值為 0 時應隱藏或改為細進度條。
- [x] 週檢視頂部「計畫／實際」摘要兩行加子欄標題約佔 120px：零值隱藏、標題列最小高度降為 72px（仍保留固定摘要高度讓下方標籤對齊）。
- 重疊事件（計時中＋實際紀錄）被擠到約 35px 寬，只剩一個字；需要最小寬度或「+N」收合。
- 「現在時間」線不明顯；可加粗、在時間軸標出時刻，開啟時自動捲到現在。
- 計畫與實際只靠空心/實心區分，對色弱不友善；可加紋理或圖示。
- 跨週的全天事件在月檢視斷開，缺少「接續」提示。

## 三、報表

- KPI 四格同大小、沒有與上一期比較；主 KPI 放大並加趨勢箭頭與百分比。
- 「18 小時 35 分」單位文字與數字同大，可改 `18h 35m` 或縮小單位。
- 工作區狀態甜甜圈太小、中心數字難讀；專案狀況進度條在 0% 時只剩一個點，像載入失敗。
- Todo Tracker 熱圖缺少時數深淺分級、hover 時數與每列合計。
- 截止提醒區塊三層顏色（左粗條、列細條、徽章）語意重複。
- 「專案時間與每日趨勢」資訊量最大卻預設收起且在最下方。

## 四、Todo

- [x] 新增表單常駐頂部約 680px 高；預設收成一行快速新增，點開才顯示進階欄位。
- [x] 每列徽章多達 5–6 個且樣式相同，「回覆設計稿」出現兩個「一般」；只強調逾期/今天到期，其餘改灰字 meta，優先級改色條。
- [x] 已依專案分組，列內又重複顯示專案名。
- [x] 「取消編輯」按鈕在非編輯狀態仍顯示（`hidden` 被 button 樣式覆蓋）。
- `[ ]` 文字核取框不像可點擊且點擊區小。
- 子任務僅以「↳」表示，縮排層級不明顯。

## 五、Popup

- 計時中時描述、專案、Todo 三個欄位重複顯示同一標題。
- 「最近紀錄」meta 文字被硬斷行，時數欄未靠右對齊。
- 可加今日目標進度條。

## 六、全域

- 沒有深色模式（`tokens.css` 無 `prefers-color-scheme`）。
- 等寬字型下中文字距過鬆，建議內文改無襯線，等寬只用於數字與時間。
- 專案顏色未檢查對比（例如 `#5b8fd0` 用於淺底文字時偏低）。
- `store-assets/` 中的週報表、Todo 截圖為概念圖，與實際 UI 差異大，上架前需對齊。
