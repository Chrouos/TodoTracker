# 每日工作回顧報表設計

## 目標

改善報表的時間軸可讀性，讓使用者能在選定的日期區間內清楚回顧「每天做了什麼」以及「每天花了多少時間」。目前 SVG 時間軸與專案分布左右並排，欄寬不足導致文字過小且工作內容難以閱讀。

## 設計決策

報表改用單欄的每日工作清單取代 SVG 時間軸。專案時間分布與 Todo 健康度保留；每日工時折線圖保留，作為數值趨勢摘要。

報表順序：

1. KPI 摘要
2. Todo 健康度
3. 專案時間分布
4. 一週工作回顧
5. 每日工時趨勢

## 每日工作回顧

每個日期是一個區塊，依日期由新到舊排列。每個區塊包含：

- 日期與星期
- 當日總工時
- 當日工作筆數
- 當日工作紀錄，依 `startedAt` 由早到晚排列

每筆工作紀錄顯示：

- 開始時間與結束時間
- 專案顏色標記與專案名稱；沒有專案時顯示一般工作
- 工作標題或描述
- 該筆工作耗時
- 有備註時，以現有 Markdown preview 顯示在工作內容下方

沒有工作紀錄的日期仍要顯示，內容標示「沒有工作紀錄」，避免使用者誤以為日期遺漏。

## 日期區間

每日工作回顧使用報表目前的篩選結果：

- 今日、本週、本月、全部：沿用現有快速區間
- 自訂區間：顯示整個選取區間的每日區塊，包含沒有紀錄的日期

現有自訂區間控制、KPI、專案分布、Todo 健康度與每日工時趨勢的篩選行為維持一致。

## 版面

- 移除報表中的 SVG 時間軸區塊，避免小字、裁切與左右欄位擁擠。
- 每日工作回顧使用單欄卡片式區塊，工作內容可自然換行。
- 專案顏色只作為工作列左側色條或色點，不再將文字壓縮到色塊內。
- 工作時間與耗時使用等寬數字，方便垂直掃讀。
- 桌面寬度與較窄視窗都維持單欄，不依賴水平捲動閱讀工作內容。
- 折線圖保留在回顧清單下方，作為每天工時的補充視圖。

## 資料與安全性

- 不新增資料欄位或資料庫結構。
- 只讀取目前已載入的 entries、projects 與報表日期區間。
- 已刪除的工作紀錄不顯示。
- 未結束的工作紀錄沿用現有報表規則，不納入已完成工時統計。
- 工作標題、描述、專案名稱與 Markdown 備註沿用現有 escaping／Markdown renderer。

## 驗證
