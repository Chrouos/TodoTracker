# 報表標題留白與 Todo 健康度設計

## 目標

改善報表區塊標題與上下內容貼得太近的問題，並在現有報表中加入可直接由現有資料計算的 Todo 健康度摘要。

## 設計

### 報表標題間距

- 報表各區塊標題保留目前的字體大小與折疊功能。
- 增加標題上下的 padding 與適度的 line-height。
- 標題與圖表之間保留明確的下方間距，跨欄與手機版使用相同的視覺規則。

### Todo 健康度

在報表 KPI 下方加入一個可折疊的「Todo 健康度」區塊，顯示：

- Todo 總數
- 已完成數與完成率
- 進行中數
- 逾期未完成數

數據使用目前所有 Todo，不受報表時間範圍影響，因為 Todo 的狀態與逾期狀態是目前工作狀態，而不是工時紀錄的區間統計。

## 資料與元件

- 在 `options.js` 的報表渲染流程計算 Todo 摘要。
- 新增純函式到 `lib/tasks.js`，讓計算可獨立測試。
- 使用現有卡片、badge 與報表 grid 樣式，不新增第三方套件或圖表類型。
- 沒有 Todo 時顯示 0 與 `—`，不產生除以零的完成率。

## 驗證

- 為 Todo 健康度純函式新增單元測試，涵蓋完成率、進行中、逾期與空資料。
- 執行既有全部 `node --test` 測試。
- 執行 JavaScript syntax check 與 `git diff --check`。
- 透過 Chrome 重新載入未封裝擴充功能確認報表標題留白與健康度區塊版面。
