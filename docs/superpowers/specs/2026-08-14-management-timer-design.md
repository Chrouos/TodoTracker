# 管理頁計時與停止完成 Todo 設計

## 目標

讓管理頁可以直接進行目前的工作計時、撰寫當下紀錄，並在停止時一次保存時間與紀錄。若計時掛有 Todo，使用者可以在停止前勾選是否完成該 Todo；預設不勾選。

## 使用流程

### 尚未計時

- 管理頁固定顯示「目前計時」區塊，不因切換報表、Todo、排程等分頁而消失。
- 使用者可選擇專案、未完成 Todo、標籤，並填寫工作描述與當下紀錄。
- 按「開始計時」後，將選擇內容保存到共用的 `timer` 資料。

### 計時中

- 顯示經過時間、工作描述、專案、Todo、標籤與紀錄欄位。
- 紀錄輸入採延遲自動保存至 `timer`，切換分頁或重新載入後可恢復。
- 若有掛 Todo，顯示「停止時標記 Todo 為完成」勾選框，初始值為未勾選。
- 沒有掛 Todo 時隱藏完成勾選框。

### 停止並儲存

- 按下「停止並儲存」後，不跳出第二次紀錄確認視窗。
- 以目前計時內容建立一筆時間紀錄，包含描述、專案、Todo、標籤與紀錄文字。
- 勾選完成選項時，將掛上的 Todo 設為 `done`；未勾選時不修改 Todo 狀態。
- 停止後清除目前計時，管理頁回到可開始計時狀態。

## 資料與元件設計

- 沿用 `db.js` 的 `getTimer`、`startTimer`、`patchTimer` 與 `stopTimer`，確保 popup 與管理頁使用同一個計時器。
- `stopTimer` 增加可選的完成 Todo 行為，維持既有未傳參數時的相容性。
- 完成 Todo 的更新只在停止時且勾選完成時執行；沒有有效 `taskId` 時不執行更新。
- 管理頁新增獨立的 timer UI 與事件處理，不複製 popup 的資料保存邏輯。
- 使用現有的時間格式化、Todo 優先度、專案樹與標籤選項元件。

## 邊界行為

- 已完成 Todo 不提供為新的掛載選項；若既有計時資料仍掛著已完成 Todo，停止時不因未勾選而改動，勾選時維持完成狀態。
- 計時尚未開始時，完成勾選框不顯示。
- 停止時沒有紀錄文字也照常建立時間紀錄。
- 停止時採用目前設定的時間四捨五入規則。
- popup 與管理頁同時開啟時，以最後一次保存的共用 `timer` 狀態為準。

## 驗證方式

- `db.js` 測試：停止計時會保存紀錄；勾選完成會將掛載 Todo 設為完成；未勾選不會改變 Todo 狀態。
- 管理頁版面測試：包含 timer 區塊、紀錄欄位與完成勾選框。
- 執行既有 Todo 優先度、階層、報表與語法檢查測試。
- 使用 `git diff --check` 確認沒有格式錯誤。
